# AmongUsOffsetsDumper

 Offsets Dumper for Among Us by **krxslaxy**.

## Features

* Dumps all available Among Us offsets
* Extracts GameAssembly methods, fields, and classes
* Automatically generates `offsets.txt`, `offsets.json`, `offsets.csv`, and `dump.cs`
* Supports selecting the game directory
* Automatically detects `GameAssembly.dll`
* Simple and easy-to-use
