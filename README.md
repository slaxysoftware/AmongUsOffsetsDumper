# AmongUsOffsetsDumper

Fast, obfuscated, and lightweight IL2CPP Offsets Dumper for Among Us by **krxslaxy**.

## Features
- Complete extraction of GameAssembly methods, fields, and classes
- Dumps directly to `offsets.txt`, `offsets.json`, `offsets.csv`, and C# pseudocode `dump.cs`
- Fully protected with Obfuscar string encryption and symbol renaming
- No anti-debug / No anti-VM checks

## Usage
Run `krxslaxy.exe` and select your game directory (or drag & drop `GameAssembly.dll`).
